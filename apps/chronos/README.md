# Chronos demo

Status: **verified synthetic artifact**, not a published planner implementation.

`demo/chronos-weekly-agenda-mock.pdf` is a one-page landscape agenda using invented events. The PNG is a preview of the same artifact. Desktop checks covered page geometry, required labels, color and grayscale distinction, and obvious visual defects.

Physical e-ink readability, handwriting comfort, annotation persistence, and on-device color remain unverified. The renderer that produced this artifact is not part of the current public candidate, so Chronos should be presented as a design/demo slice.

Not implemented: calendar import, a public renderer, task sync, handwriting extraction, regeneration, or automated device delivery.
